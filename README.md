# Nuc-Metrics [IN] ⚛️

**Live:**(https://nuc-matrics-india.vercel.app/)

A high-end, interactive educational platform exploring India's atomic history and global nuclear mechanics. Built with a premium, futuristic blueprint aesthetic.

## 📂 Project Structure
* `index.html` - **The Physics:** Core mechanics & interactive reactor simulator.
* `timeline.html` - **The Journey:** Chronological history of Indian and global atomic milestones.
* `strategy.html` - **The Strategy:** India's 3-stage nuclear program and active fleet status.
* `game.html` - **The Game:** *Reactor Tycoon*, an integrated incremental energy-mining game with local save states.

## 🛠️ Tech Stack
**100% Pure HTML, CSS, and Vanilla JavaScript.** No external frameworks or libraries. Deployed via Vercel.
